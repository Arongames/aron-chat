Aron Chat
Версия 1.9.0 · 2026
Разработчик: SGR (StreamRateGame)

Чат TikTok LIVE, Twitch и YouTube в одном окне, облачная озвучка Speechify, оверлей для OBS и счётчики зрителей.

Поддержать проект

Aron Chat бесплатный и без рекламы. Если приложение помогает в стримах, можно поддержать разработку донатом — это ускоряет новые функции и исправления.

Что умеет

  • Три чата в одной ленте с бейджами подписок и подарков.
  • Озвучка сообщений, подписок и подарков через Speechify.
  • Кастомные команды: на триггер озвучивается заготовленный ответ.
  • Фильтры: префиксы, боты, стоп-фразы.
  • Оверлей для OBS и счётчики зрителей Twitch, YouTube, TikTok.

Технологии

  • Electron 33, Node.js.
  • tiktok-live-connector, tmi.js, YouTube Data API v3.
  • Speechify API (simba) и WebSocket-оверлей.
