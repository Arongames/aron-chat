## Локализация

- Добавлены шаблоны перевода для строк с параметрами:
  - `Вход выполнен: …` → `Signed in: …`
  - `Не отправлено: …` → `Not sent: …`
  - `Настройки сохранены: …` → `Settings saved: …`
  - `Пользователь … скрыт` → `User … hidden`
  - `Код … — подтвердите на …` → `Code … — confirm at …`
  - `…: … подключён` → `…: … connected`
  - `Скачивание… 42% (120 МБ)` → `Downloading… 42% (120 MB)`
  - `У вас последняя версия (…)` → `You are up to date (…)`
  - `Проверка через N с (попытка M)` → `Checking in N s (attempt M)`
  - пресеты, экспорт/импорт, копирование адреса, CSS оверлеев и другие.
- Шаблоны применяются и к динамически добавленным элементам.

## Ограничения

- Часть динамических строк с переменными ещё может оставаться на русском.
- Lite-сборка не содержит Piper; TTS через Speechify.
- TikTok — неофициальный WebSocket и подпись Euler Stream.
- YouTube — квота Data API v3; для отправки нужен OAuth.
- Twitch — для отправки нужен OAuth; для Confidential-приложения также Client Secret.
- Файлы не подписаны — SmartScreen предупреждает.
