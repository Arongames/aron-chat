## Исправлено

- **Дубли сообщений YouTube.** Одно и то же сообщение больше не появляется дважды: чат дедуплицируется по `id` сообщения.
- **Лишние перечитывания.** Если YouTube не вернул `nextPageToken`, приложение больше не запрашивает последнюю страницу чата повторно.

## Контекст

- В 1.10.30 исправлен сам YouTube-чат: путь API изменён с `liveChatMessages` на `liveChat/messages` (старый отдавал пустой 404).
- Свои отправленные сообщения появляются в ленте сразу.
- Работает лог `aron.log` и кнопка «Открыть лог».

## Установка

1. Скачайте `Aron Chat Setup 1.10.31.exe`.
2. SmartScreen может предупредить — «Подробнее → Всё равно запустить».
3. После установки при необходимости переподключите YouTube:
   «Площадки» → YouTube → «Отключить» → «Подключить».
