## Новое

- **DonationAlerts.** В «Доступ» появился блок:
  - «Войти через DonationAlerts» — OAuth с локальным callback `http://127.0.0.1:17342/da-callback`;
  - «Принимать донаты» — показывать новые донаты в окне «События» и оверлее;
  - «Озвучивать донаты» — читать сумму и сообщение через TTS.
- Донаты опрашиваются раз в 30 секунд, повторно не показываются.
- События донатов идут с суммой, валютой и сообщением.

## Техническое

- OAuth-токены DonationAlerts хранятся зашифрованными (DPAPI), как Twitch/Google.
- При истечении access token выполняется refresh.
- Client ID приложения — `22509`, redirect URI уже настроен.
- Добавлен логотип-сердечко для донатов в ленте и оверлее.

## Проверка

- e2e: **23/23**.
- Кнопки и переключатели DonationAlerts присутствуют в «Доступ».

## Установка

1. Скачайте `Aron Chat Setup 1.10.33.exe`.
2. «Доступ» → DonationAlerts → **«Войти через DonationAlerts»**.
3. Подтвердите доступ в браузере; вкладку можно закрыть.
4. Включите «Принимать донаты» и при желании «Озвучивать донаты».

## Ограничения

- DonationAlerts API имеет лимит 60 запросов/мин; приложение ходит раз в 30 секунд.
- Для входа приложение DonationAlerts должно иметь redirect URI `http://127.0.0.1:17342/da-callback`.
- TikTok — неофициальный WebSocket и подпись Euler Stream.
- YouTube — квота Data API v3; для отправки нужен OAuth.
- Twitch — для отправки нужен OAuth; для Confidential-приложения также Client Secret.
- Файлы не подписаны — SmartScreen предупреждает.
