# Идеи для следующих версий

Черновик к утру: что уже сделано в 1.9.0 и что можно добавить дальше.
Оценки: **S** — до пары часов, **M** — день, **L** — несколько дней.

## Уже в 1.9.0

- Оверлей разделён на два независимых Browser Source: чат `/overlay/chat` и зрители `/overlay/viewers`.
- Сервер оверлеев слушает только `127.0.0.1`, порт настраивается (3000–3010 при занятости).
- Счётчики зрителей: Twitch (Helix, нужен Client ID), YouTube (Data API), TikTok (приблизительно).
- Фильтры озвучки: префиксы, боты, стоп-фразы + общий тумблер.
- Все настройки в одном месте; черновик, кнопка «Сохранить», автосохранение при закрытии.
- Новый интерфейс в стиле Hibiki: палитра `#0b0d11`/`#30b586`, рейл 56 px, шрифты Tektur + Exo 2.
- Очередь TTS вместо потери сообщений, голос `alexei`, ключ из `SPEECHIFY_API_KEY`.
- Исправлены: статус TikTok с ником, кнопка maximize, мёртвая зависимость `obs-websocket-js`.

## 1. Ближайшее и дешёвое (S)

1. **Пресеты оверлея** — готовые наборы «компактный / крупный / только донаты» одной кнопкой.
2. **Горячие клавиши**: пауза озвучки, очистка ленты, переключение страниц.
3. **Экспорт/импорт настроек** в JSON — перенос между компьютерами.
4. **Резервная копия config.json** (`.bak` при каждом сохранении) и кнопка «восстановить».
5. **Счётчик сообщений за сессию** и кнопка сброса статистики.
6. **Скрыть/показать платформу в ленте** — фильтр по TikTok/Twitch/YouTube.
7. **Копирование сообщения** по клику, выделение текста в ленте.

## 2. Модерация и порядок в чате (M)

8. **Скрытые пользователи**: локальный мут — сообщения не показываются в ленте и оверлее.
9. **Ключевые слова/хайлайты**: подсветка сообщений с заданными словами.
10. **Закреплённое сообщение** в оверлее (pinned) — удобно для правил/ссылок.
11. **Удаление сообщения из оверлея** одним кликом (без удаления на площадке).
12. **Панель модератора** по локальной ссылке с токеном: мут, пауза TTS, скрытие виджетов.
13. **Поиск по ленте** и экспорт чата в текстовый файл.

## 3. Озвучка (M)

14. **Громкость и «дакинг»** — приглушать музыку/игру, пока говорит TTS (через OBS или WASAPI).
15. **Скорость и тон** для Speechify, если API поддерживает.
16. **Озвучка только донатов** — порог по количеству монет.
17. **Чистка текста**: вырезать ссылки, эмоуты, CAPS, повторы, мат-фильтр.
18. **Разные голоса для площадок** (TikTok — один, Twitch — другой) как опция.
19. **Индикатор очереди** в статусбаре (сколько фраз ждёт синтеза).
20. **Локальный fallback** на системный голос (Web Speech), если Speechify недоступен.

## 4. Виджеты и алерты (M/L)

21. **Алерт-виджет** на подписку/подарок с анимацией — отдельный Browser Source.
22. **Топ лайкеров / топ донатеров** за эфир (данные TikTok).
23. **Цель эфира**: подписчики/донаты — прогресс-бар в оверлее.
24. **Кастомный CSS** для каждого виджета прямо в настройках (поле с предпросмотром).
25. **Эмоуты и аватары**: подтягивать Twitch/BTTV/7TV эмоуты и аватары пользователей.
26. **Темы виджетов**: Hibiki-dark, минимал, неон — переключатель.
27. **Позиции сеткой**: привязка к сетке 10 px и подсказки безопасных зон OBS.

## 5. Интеграция с OBS и стримом (M/L)

28. **obs-websocket**: автосоздание двух Browser Source при первом запуске, переключение сцен.
29. **Таймстемпы/хайлайты** (как в Hibiki): горячая клавиша помечает момент, сохраняется список с ссылками на Twitch/YouTube.
30. **Статистика эфира**: сообщения, уникальные пользователи, подарки, подписки; сохранение по сессиям и CSV.
31. **Автозапись/маркер** через OBS при старте эфира.

## 6. Площадки (M/L)

32. **Twitch OAuth**: отправка сообщений из приложения, сабы, рейды.
33. **YouTube OAuth**: точные `concurrentViewers` и отправка сообщений.
34. **TikTok**: каталог подарков и стоимость в монетах, топ гифтеров, агрегация комбо.
35. **VK Live / Kick** как новые площадки (по запросу).

## 7. Инфраструктура (S/M)

36. **Автообновление** через `electron-updater` + канал portable.
37. **Логи в файл** с ротацией (сейчас только консоль и панель событий).
38. **Юнит-тесты** для `config.js` (миграции, sanitize) и фильтров — быстро и полезно.
39. **First-run мастер**: 3 шага — ключ Speechify, площадки, адреса оверлеев.
40. **Английская локализация** интерфейса.

## Что стоит решить отдельно

- **Ключи в `config.json`**: сейчас в проекте лежит рабочий ключ Speechify и ключ YouTube API. Для portable это ожидаемо, но файл нельзя передавать вместе с проектом. Варианты: (а) вынести `config.json` из репозитория и добавить в `.gitignore`; (б) хранить ключ через `safeStorage` (шифрование DPAPI) — ломает переносимость конфига между ПК; (в) оставить как есть, но добавить предупреждение при экспорте настроек.
- **TikTok-зрители**: число приблизительное (Webcast не отдаёт точный онлайн). Оставляем как есть или убираем TikTok из счётчиков?
- **Порт оверлея**: фиксированный 3000 или автоподбор при каждом запуске? Сейчас 3000 с запасным диапазоном, но OBS-ссылка меняется, если порт занят.

## Мои приоритеты на 1.10

1. Алерт-виджет + топ донатеров (сильнее всего влияет на стрим).
2. Модерация: скрытые пользователи и хайлайты (дешево, заметно).
3. OBS-интеграция и таймстемпы (фича Hibiki, которой у нас нет).
4. Чистка текста и громкость TTS (качество звука).
5. Юнит-тесты конфига и first-run мастер (надёжность).
