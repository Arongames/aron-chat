## Важное исправление: тихое обновление и пробелы в пути

В 1.10.39 при обновлении установленной версии путь `C:\Program Files\Aron Chat`
при повышении прав разбивался на `C:\Program`. Установщик ставил копию в `C:\Program`.

Исправлено:

- путь передаётся **файлом** `%TEMP%\aron-update-target.txt`, а не аргументом командной строки;
- установщик принимает `--dir` только если в этой папке уже лежит `Aron Chat.exe`;
- при повышении прав путь больше не участвует в командной строке — используется файл или поиск установленной копии;
- ошибочная папка `C:\Program` удалена, ярлыки и запись в реестре восстановлены на `C:\Program Files\Aron Chat`.

Обновление со старой версии 1.10.38 теперь тоже безопасно: установщик 1.10.40
проверит путь и при кривом `--dir` найдёт реальную установку сам.

## Функции 1.10.39 в этой сборке

- **Автосообщения по таймеру:** площадка, интервал, минимум активности, список по кругу.
- **Мини-режим:** компактное окно только с чатом, всегда сверху, восстановление размера.
- **Редактор оверлея:** перетаскивание блока «Чат» по сетке 16:9, сохранение координат.

## Ограничения

- Для `C:\Program Files` тихая установка требует UAC — окно установщика не появляется.
- Автосообщения в TikTok не поддерживаются.
- Для YouTube-автосообщений нужен OAuth и подключённый чат.
- Lite не содержит Piper; TTS через Speechify.
- Файлы не подписаны — SmartScreen предупреждает.
