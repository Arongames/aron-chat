## Исправлено

- **Twitch: не показывался онлайн.** Helix требует OAuth-токен, а запрос шёл только с Client ID. Теперь используется токен, а без него — резервный публичный GQL-запрос, как у веб-плеера. Счётчик снова видит эфир.
- **YouTube: не загружался чат.** Чат `liveChatMessages` требует OAuth, а модуль получал только API-ключ. Теперь при подключении передаётся access token, и сообщения читаются.
- **Озвучка накладывалась сама на себя.** Добавлена очередь воспроизведения: следующий файл стартует только после окончания предыдущего.
- **Оверлей зрителей:** убраны подписи площадок, остались только логотипы и числа. Логотипы YouTube/Twitch/TikTok используются вместо цветных точек.

## Новое

- В оверлее площадки теперь обозначаются значками, а не текстом — компактнее для OBS.
- Очередь TTS работает и для Speechify, и для Piper: голос не перебивает сам себя.

## Проверка

- Twitch GQL возвращает зрителей для `arongamesn1` (3 в момент проверки).
- e2e: **23/23**.
- YouTube-фикс проверен структурно: токен теперь доходит до `youtube.start`; для полной проверки нужен вход в Google.

## Установка

1. Скачайте `Aron Chat Setup 1.10.21.exe`.
2. SmartScreen может предупредить — «Подробнее → Всё равно запустить».
3. Если YouTube-чат не появился — проверьте, что вход в Google выполнен и трансляция идёт.
4. Twitch-онлайн обновляется раз в 30 секунд.
