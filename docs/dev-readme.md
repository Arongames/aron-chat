# Aron Chat 1.10

Чат TikTok LIVE, Twitch и YouTube в одном окне, две озвучки (Speechify и офлайн Piper),
два независимых оверлея для OBS, счётчики зрителей, эмоуты и аватары.

## Возможности

- **Единая лента** трёх площадок: сообщения, подписки, подарки, входы.
- **Две озвучки**: Speechify (облако, ключ) и **Piper** (офлайн, голоса Dmitri и Irina).
  Движок выбирается в настройках; есть громкость и скорость.
- **Аватары** YouTube/Twitch/TikTok и **эмоуты** 7TV, BTTV, FFZ.
- **Кастомные команды**: на триггер (`!дискорд`) озвучивается заготовленный ответ.
- **Фильтры озвучки**: префиксы, боты, стоп-фразы и полное скрытие пользователей.
- **Два оверлея для OBS** с отдельными адресами, позициями, масштабом и своим CSS:
  - чат — `http://127.0.0.1:3000/overlay/chat`
  - зрители — `http://127.0.0.1:3000/overlay/viewers`
- **Счётчики зрителей**: Twitch Helix (нужен Client ID), YouTube Data API, TikTok (приблизительно).
- **Настройки** отдельными вкладками, с черновиком и кнопкой «Сохранить»; при закрытии
  несохранённое сохраняется само. Есть экспорт/импорт и резервная копия `config.json.bak`.

## Запуск из исходников

```powershell

```

## Отправка сообщений (OAuth)

- **Twitch**: на карточке площадки укажите Client ID приложения
  (<https://dev.twitch.tv/console/apps>), затем «Настройки → Доступ → Войти через Twitch».
  Приложение покажет код, откроет `twitch.tv/activate`; пароль вводится только на Twitch.
- **YouTube**: создайте OAuth-клиент типа «Desktop app» в Google Cloud, включите
  YouTube Data API v3 и вставьте Client ID и Client Secret в раздел «Доступ».
  Кнопка «Войти через Google» откроет браузер; после подтверждения можно отправлять сообщения.
- Панель отправки находится под лентой чата: выберите площадку, введите текст, Enter.

## Цифровая подпись

Пока exe не подписан, Windows SmartScreen показывает «Неизвестный издатель» —
это нормально для новых сборок, установке не мешает (кнопка «Запустить»).

Убрать предупреждение навсегда можно только сертификатом подписи кода:

1. Купить сертификат Code Signing (OV или EV) у удостоверяющего центра.
2. Добавить в сборку переменные окружения перед `npm run build`:

```powershell
$env:CSC_LINK = "C:\path\to\certificate.pfx"   # или base64
$env:CSC_KEY_PASSWORD = "пароль"
npm run build
```

electron-builder подпишет и приложение, и установщик. EV-сертификат (на токене)
даёт мгновенную репутацию в SmartScreen, OV — со временем и числом установок.

## Сборка

```powershell
npm run build            # portable + кастомный установщик
npm run build:portable   # dist-new\Aron Chat 1.10.4.exe
npm run build:setup      # dist-setup\Aron Chat Setup 1.10.4.exe
npm run build:nsis       # запасной NSIS-установщик
```

Установщик (`installer/`) — отдельное Electron-приложение в стиле Aron Chat:
условия с обязательным принятием, выбор папки, прогресс, ярлыки, запись в
«Приложения и возможности» и собственный uninstaller. Издатель — SGR (StreamRateGame),
по умолчанию ставится в `%LOCALAPPDATA%\Programs\Aron Chat` без прав администратора.

## Где лежат настройки

`config.json` рядом с приложением:

- portable — в папке с `.exe`;
- разработка — в корне проекта;
- установленная версия — `%APPDATA%\Aron Chat\config.json`.

Ключ Speechify можно задать в настройках или переменной окружения
`SPEECHIFY_API_KEY` (она имеет приоритет, если поле пустое).

## Оверлеи в OBS

1. Вкладка **Виджеты** → скопировать адрес чата.
2. В OBS: источник **Browser Source**, вставить адрес, ширина/высота сцены
   (например 1920×1080), фон прозрачный.
3. Повторить для адреса зрителей — это отдельный источник, его можно поставить в другой угол.
4. Позиция и масштаб каждого виджета настраиваются отдельно, изменения видны сразу.

## Twitch Client ID

Счётчик Twitch использует Helix API и требует Client ID приложения:
<https://dev.twitch.tv/console/apps> → создать приложение → скопировать Client ID
в настройки площадки. Без него чат работает, счётчик — нет.

## Известные ограничения

- YouTube без OAuth показывает просмотры трансляции, а не точный онлайн.
- TikTok отдаёт только приблизительное число зрителей.
- Отправлять сообщения в чат площадок приложение не умеет — только читает и озвучивает.
- В `config.json` проекта могут лежать рабочие ключи: не передавайте файл третьим лицам.
