## Локализация

- Динамические элементы теперь тоже переводятся: тосты, статусы сохранения, кнопки, подписи, появляющиеся после переключения языка.
- Добавлен наблюдатель за DOM: новые тексты переводятся на лету.
- Расширен словарь: «Сообщение отправлено», «Скачивание…», «Запускаю установщик…», «Вы вышли…», «DonationAlerts подключён» и другие.
- Динамические строки с подстановками (имена, суммы, коды ошибок) пока остаются на русском — для них нужен отдельный проход с параметрами.

## Безопасность DonationAlerts

- **Client Secret больше не вшит в builtin.js** — убран из сборки.
- Добавлены поля «DonationAlerts Client ID» и «Client Secret» в «Доступ → Продвинутые настройки».
- Секрет хранится в `config.json` зашифрованным через DPAPI (`enc:v1:`), как остальные токены.
- Redirect URI: `http://127.0.0.1:17342/da-callback`.

## Установщик

- Включён фикс 1.10.35: при обновлении поле папки показывает текущую установку (`C:\Program Files\Aron Chat`), а не путь по умолчанию.

## Ограничения

- Английская локализация не покрывает строки с подстановками (имена, суммы, статусы с переменными).
- Lite-сборка не содержит Piper; TTS через Speechify.
- TikTok — неофициальный WebSocket и подпись Euler Stream.
- YouTube — квота Data API v3; для отправки нужен OAuth.
- Twitch — для отправки нужен OAuth; для Confidential-приложения также Client Secret.
- Файлы не подписаны — SmartScreen предупреждает.
