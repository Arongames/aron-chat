## Новое

- **Обновление из приложения.** Кнопка «Скачать и установить» теперь скачивает установщик прямо внутри приложения, показывает прогресс в процентах и мегабайтах и запускает его. После запуска приложение закрывается, установка идёт как обычно.
- **Акцентные темы.** «Настройки → Чат и оформление → Акцентный цвет»:
  - Мята (по умолчанию)
  - Фиолетовый
  - Синий
  - Розовый
  - Янтарный

  Тема применяется сразу и сохраняется в конфиге.

## Как это работает

1. «О программе» → «Проверить обновления».
2. Если есть новая версия — окно «Что нового» с заметками релиза.
3. «Скачать и установить» → прогресс → запуск установщика.

Ссылка на файл берётся из последнего GitHub-релиза. Для проверки нужен опубликованный релиз `v1.10.32` с прикреплённым установщиком.

## Ограничения

- Автообновление запускает установщик, но не ставит его молча — нужен клик в установщике.
- TikTok — неофициальный WebSocket и подпись Euler Stream.
- YouTube — квота Data API v3; для отправки нужен OAuth.
- Twitch — для отправки нужен OAuth; для Confidential-приложения также Client Secret.
- Файлы не подписаны — SmartScreen предупреждает.
