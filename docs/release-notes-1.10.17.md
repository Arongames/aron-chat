## Новое

- **Окно «События»** — лайки, подписки и подарки больше не смешиваются с чатом.
- **Лайки TikTok по каждому зрителю** — одна строка на человека: «лайкнул ×3 · всего 5».
- **Блокировка пользователя в один клик** — при наведении на сообщение появляется «×»; сообщения исчезают сразу и больше не показываются.
- **Размер текста чата** — «Настройки → Чат», плюс быстрые кнопки **A− / A+** в шапке чата. Применяется к приложению и оверлею.
- **Крупные значки платформ справа** — размер настраивается (14–40 px), можно выключить.
- **Поиск по настройкам** — вводишь «озвучка», «TikTok», «ключ» и остаются только подходящие разделы.
- **Настройки-вкладки** — открыт только выбранный раздел, а не вся простыня.
- **Свободный размер окна** — от 560×420, без обрезания интерфейса.
- **Twitch Client Secret** — необязательное поле для приложений типа Confidential и понятное предложение войти заново, если секрета нет.
- **Шифрование секретов** — ключ Speechify, API-ключ YouTube и OAuth-токены хранятся в `config.json` зашифрованными (Windows DPAPI).
- **Безопасный экспорт** — файл настроек больше не содержит ключей и токенов.

## Исправлено

- **TikTok: сообщения не отображались.** Коннектор отдаёт текст в `content` и автора в `user`, а приложение читало старые `comment`/`uniqueId` — отсюда пустой чат и «гость».
- **Ошибка `reading 'map'`** при подключении TikTok.
- **Растянутый аватар в оверлее** — картинка занимала всю строку вместо кружка 28 px.
- **Офлайн-площадки в оверлее зрителей** — YouTube и Twitch висели с «—»; теперь показываются только площадки с активным эфиром, а если таких нет — скрывается весь блок.
- **Обрезание длинных сообщений** — текст переносится на несколько строк, ничего не отрезается.
- **Ссылки оверлея больше не меняются** — порт фиксированный (3000), без тихого переезда на 3001/3002.
- **При сужении окна пропадали разделы настроек** — теперь они собираются в горизонтальную ленту.
- **Отправка в Twitch** — добавлен scope `user:write:chat` и обработка ошибки «missing client secret».

## Под капотом

- Переход на основную ESM-сборку `tiktok-live-connector` (legacy оставлен как запасной).
- Нормализация событий TikTok: чат, лайки, подарки, подписки.
- Дедупликация истории чата при подключении.
- Секреты не попадают в git и в экспорт; встроенные OAuth-ключи вынесены в локальный `src/main/builtin.js`.
- Репозиторий на GitHub с чистой историей и README.

## Установка

1. Скачайте `Aron Chat Setup 1.10.17.exe`.
2. Windows может показать SmartScreen «Неизвестный издатель» — это нормально для неподписанной сборки: «Подробнее → Всё равно запустить».
3. Установка по умолчанию — в профиль пользователя, без прав администратора. В `C:\Program Files` потребуется UAC.
4. Если вы пользовались Twitch-отправкой — после установки **выйдите и войдите в Twitch заново** («Доступ → Выйти → Войти через Twitch»).

## Известные ограничения

- **TikTok** — неофициальный WebSocket и подпись Euler Stream. Возможны лимиты и перебои; отправка сообщений в TikTok не поддерживается.
- **YouTube** — нужен свой API-ключ и квота Data API v3.
- **Twitch** — для отправки нужен OAuth; для Confidential-приложения также Client Secret.
- Файлы не подписаны сертификатом — SmartScreen будет предупреждать.
