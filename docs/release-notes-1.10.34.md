## Новое

### Английская локализация — первый проход

- В «Настройки → Чат и оформление» добавлен переключатель **Язык интерфейса: Русский / English**.
- Переведены основные экраны: рейл, заголовки страниц, вкладки настроек, лента, панель отправки, площадки, озвучка, фильтры, зрители, доступ, команды, данные, «О программе», обновления, донат.
- Статические подписи переводятся на месте, без перезапуска.
- Динамические статусы, тосты и логи пока остаются на русском — это следующий проход.

### Лёгкая сборка Lite

- Отдельный portable-EXE **без офлайн-голосов Piper**.
- Размер: **≈73 МБ** вместо ≈272 МБ.
- TTS работает через Speechify (нужен API-ключ); Piper в Lite недоступен.
- Все остальные функции на месте: TikTok, Twitch, YouTube, оверлеи, DonationAlerts, темы, обновления.

## Ограничения

- Английская локализация пока не покрывает динамические сообщения (статусы, ошибки, тосты).
- Lite не содержит Piper: офлайн-озвучка недоступна, только Speechify.
- TikTok — неофициальный WebSocket и подпись Euler Stream.
- YouTube — квота Data API v3; для отправки нужен OAuth.
- Twitch — для отправки нужен OAuth; для Confidential-приложения также Client Secret.
- Файлы не подписаны — SmartScreen предупреждает.
