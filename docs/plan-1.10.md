## Что нужно от тебя

1. **Twitch Client ID** — уже есть (поле в настройках) или создать приложение на dev.twitch.tv.
   Для OAuth-входа хватит Client ID, без секрета (device code flow).
2. **Google OAuth**: Client ID и Client secret типа «Desktop app» из Google Cloud Console
   + включённый YouTube Data API v3. Без них отправка в YouTube и точный онлайн невозможны.
3. **Голоса Edge TTS**: по умолчанию возьму `ru-RU-DmitryNeural` (мужской) и
   `ru-RU-SvetlanaNeural` (женский), список будет в настройках.

## Объяснения

- **9. Хайлайты** — сообщения с заданными словами подсвечиваются в ленте и оверлее
  (например, «вопрос», «донат», «ссылка»), чтобы не пропустить важное. При малом
  потоке сообщений польза небольшая.
- **12. Панель модератора** — отдельная веб-страница с одноразовым токеном, чтобы друг
  мог замьютить пользователя или поставить TTS на паузу. Работает только в локальной
  сети; снаружи нужен туннель (Cloudflare Tunnel/ngrok) или сервер. Пока нет ни того,
  ни другого — делать рано.
- **27. Сетка позиций** — в предпросмотре виджета включается сетка 10/20 px, чтобы
  края карточек выравнивались. Косметика, можно позже.
- **37. Логи в файл** — приложение пишет диагностику рядом с config.json, чтобы после
  падения или обрыва стрима можно было понять причину. Полезно, но не срочно.
- **38. Юнит-тесты** — автоматические проверки миграций конфига и фильтров, чтобы
  обновления не ломали настройки. Пользователю не видны, нужны мне для надёжности.
