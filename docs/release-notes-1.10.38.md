## Тихая установка — для всех вариантов

- **Установленная версия:** приложение скачивает Setup и запускает его с `--silent --dir <текущая папка> --launch`. Окно установщика не появляется, кликать не нужно. Если папка требует прав администратора, Windows покажет только UAC.
- **Portable полная:** скачивает новый portable-EXE, заменяет себя после закрытия и перезапускается.
- **Lite:** то же самое — скачивает `Aron Chat Lite <версия>.exe`, заменяет себя и перезапускается.
- `config.json` и настройки не затрагиваются.
- После скачивания проверяется SHA-256 из GitHub-ассета (если digest есть).

## Ограничения

- Для папки в `Program Files` тихая установка требует подтверждения UAC — это ограничение Windows, окно установщика при этом не открывается.
- Часть динамических строк приложения всё ещё на русском.
- GitHub digest есть только у ассетов, загруженных после появления этой функции.
- Lite не содержит Piper; TTS через Speechify.
- TikTok — неофициальный WebSocket и подпись Euler Stream.
- YouTube — квота Data API v3; для отправки нужен OAuth.
- Twitch — для отправки нужен OAuth; для Confidential-приложения также Client Secret.
- Файлы не подписаны — SmartScreen предупреждает.
