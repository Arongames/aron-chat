## Lite обновлён до 1.10.38

- Lite теперь **обновляется из приложения**, как полная версия.
- При проверке обновления Lite ищет в релизе ассет `Aron Chat Lite <версия>.exe`, а не Setup.
- После скачивания запускается помощник: ждёт закрытия приложения, заменяет portable-EXE и перезапускает его.
- Настройки и `config.json` не затрагиваются.

## Локализация оверлея

- При `English` оверлей переключается:
  - «Зрители» → **Viewers**;
  - события: `followed`, `subscribed`, `sent a gift`, `joined`, `liked`, `donated`.
- Язык передаётся вместе с настройками — достаточно обновить Browser Source.

## Безопасность обновлений

- SHA-256 берётся из `digest` GitHub-ассета.
- После скачивания установщик/EXE хэшируется и сверяется.
- При несовпадении файл удаляется, установка не запускается.
- Если digest отсутствует (старые ассеты), проверка пропускается.

## Ограничения

- Часть динамических строк приложения всё ещё на русском.
- GitHub digest есть только у ассетов, загруженных после появления этой функции.
- Lite не содержит Piper; TTS через Speechify.
- TikTok — неофициальный WebSocket и подпись Euler Stream.
- YouTube — квота Data API v3; для отправки нужен OAuth.
- Twitch — для отправки нужен OAuth; для Confidential-приложения также Client Secret.
- Файлы не подписаны — SmartScreen предупреждает.
