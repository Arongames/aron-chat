## Главное

- **YouTube-чат теперь подключается.** `liveChatMessages` требует OAuth, а приложение отправляло только API-ключ. Теперь access token передаётся в чат.
- **Токен обновляется автоматически.** При 401/403 приложение получает новый access token и повторяет запрос, не дожидаясь перезапуска.
- **Истёкший вход сбрасывается.** Если Google отозвал refresh token, приложение честно покажет «войдите заново», а не будет молча ждать сообщений.

## Исправлено

- **YouTube: пустой чат при активной трансляции** — исправлена передача OAuth-токена и обновление при истечении.
- **Twitch: не показывался онлайн** — Helix требует Bearer-токен; теперь используется токен, а без него — публичный GQL-запрос. Счётчик снова видит эфир.
- **Озвучка накладывалась** — добавлена очередь: следующий файл играет только после окончания предыдущего.
- **Оверлей зрителей** — убраны подписи площадок, остались только логотипы и числа.
- **Окно «Что нового»** — при обновлении показываются заметки релиза с GitHub, кнопки «Скачать» и «Позже».

## Новое

- Логотипы YouTube/Twitch/TikTok в оверлее вместо цветных точек.
- Очередь TTS для Speechify и Piper.
- Проверка обновлений с просмотром changelog.
- Шифрование ключей и токенов, безопасный экспорт настроек.

## Что сделать после установки

1. Установите 1.10.22.
2. Откройте **«Доступ» → Google / YouTube → «Выйти»**, затем **«Войти через Google»** — старый токен истёк.
3. На «Площадках» подключите YouTube `@AronGames` заново.
4. Убедитесь, что на трансляции включён чат.
