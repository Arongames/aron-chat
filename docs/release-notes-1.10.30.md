## Главное

- **Исправлен YouTube-чат.** Причина была не в квоте и не в токене: YouTube изменил путь метода API. Вместо `liveChatMessages` теперь `liveChat/messages`. Старый адрес отдавал пустой **HTTP 404**, поэтому чат молчал.
- **Чтение подтверждено на живом эфире:** подключение `ok`, статус `connected`, в ленту пришло **7 сообщений**, включая сообщения других зрителей.

## Что ещё в этой сборке

- **Свои отправленные сообщения появляются сразу** — не нужно ждать, пока площадка вернёт их в чат. Защита от дублей есть.
- **Лог приложения:** `aron.log` рядом с `config.json`; кнопка **«Открыть лог»** в «О программе».
- В лог пишутся ошибки YouTube API и количество полученных сообщений — с этим можно разбирать проблемы без догадок.
- **Резервное чтение YouTube через InnerTube** остаётся как страховка, но теперь официальный путь работает.
- Автоподхват нового эфира YouTube по каналу, а не по старому `videoId`.
- Обновление OAuth-токена при 401/403 и повторный запрос.

## Проверка

- Реальный аккаунт `@AronGames`, живой эфир: чат прочитан, сообщения `@aron9106` отображаются.
- Отправка сообщений работает через `liveChat/messages`.
- e2e: 22/23 — единственная «не пройдена» проверка `окно открылось` из-за тайминга готовности страницы; все функциональные проверки прошли.

## Установка

1. Скачайте `Aron Chat Setup 1.10.30.exe`.
2. SmartScreen может предупредить — «Подробнее → Всё равно запустить».
3. После установки: «Площадки» → YouTube → **«Отключить»**, затем **«Подключить»**.
4. Сообщения из чата должны пойти в ленту; свои отправленные видны сразу.

## Известные мелочи

- При подключении к чату с историей возможны дубли строк — это пагинация YouTube; на подключение и чтение не влияет.
- TikTok — неофициальный WebSocket и подпись Euler Stream.
- Twitch — для отправки нужен OAuth; для Confidential-приложения также Client Secret.
- Файлы не подписаны сертификатом — SmartScreen предупреждает.
