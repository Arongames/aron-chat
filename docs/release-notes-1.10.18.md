## Главное

- **Проверка обновлений.** В «О программе» появилась кнопка «Проверить обновления» и кнопка «Скачать» рядом с новой версией.
- **Автопроверка при запуске** — один раз за запуск, без автоматического скачивания и установки.
- **Свой адрес проверки** — можно указать `latest.json` или GitHub API в «О программе → Свой адрес проверки». По умолчанию — последний релиз `Arongames/aron-chat`.
- **Twitch Client Secret** — необязательное поле для приложений типа Confidential. Если секрета нет, приложение предлагает войти заново вместо ошибки «missing client secret».

## Новое

- Проверка обновлений через GitHub Releases или собственный `latest.json` (версия, заметки, ссылка, дата).
- Поле **Twitch Client Secret** в «Доступ → Продвинутые настройки».
- **Шифрование секретов** в `config.json`: ключ Speechify, API-ключ YouTube, OAuth-токены и Twitch-секрет хранятся через Windows DPAPI.
- **Безопасный экспорт настроек** — файл не содержит ключей и токенов.
- **Поиск по настройкам** — фильтрация разделов по запросу.
- **Размер текста чата** (Настройки → Чат) и быстрые кнопки **A− / A+** в шапке чата.
- **Крупные значки платформ справа** с настройкой размера и возможностью отключить.
- **Окно «События»** — лайки, подписки и подарки отдельно от чата.
- **Счётчики лайков TikTok по зрителям** — одна строка на человека, «лайкнул ×3 · всего 5».
- **Блокировка пользователя** по «×» при наведении; сообщения исчезают сразу.
- **Свободный размер окна** — от 560×420.

## Исправлено

- **TikTok: пустой чат и «гость»** — приложение читало `comment`/`uniqueId`, а коннектор отдаёт `content`/`user`.
- **Ошибка `reading 'map'`** при подключении TikTok.
- **Растянутый аватар в оверлее** — картинка занимала всю строку.
- **Офлайн-площадки в оверлее зрителей** — показываются только площадки с активным эфиром; если таких нет, блок скрывается.
- **Обрезание длинных сообщений** — текст переносится на несколько строк.
- **Прыгающие ссылки оверлея** — порт фиксированный (3000), без переезда на 3001/3002.
- **Пропадающие разделы настроек при сужении окна** — теперь горизонтальная лента.
- **Отправка в Twitch** — добавлен scope `user:write:chat`, понятная ошибка при нехватке прав.

## Под капотом

- Переход на основную ESM-сборку `tiktok-live-connector`, legacy оставлен запасным.
- Нормализация событий TikTok и дедупликация истории чата.
- Встроенные OAuth-ключи вынесены из публичного репозитория в локальный `src/main/builtin.js`.
- Репозиторий: <https://github.com/Arongames/aron-chat>, README со скриншотами.

## Установка

1. Скачайте `Aron Chat Setup 1.10.18.exe`.
2. SmartScreen может показать «Неизвестный издатель» — «Подробнее → Всё равно запустить».
3. Установка по умолчанию в профиль пользователя, без прав администратора. В `C:\Program Files` потребуется UAC.
4. Если пользовались отправкой в Twitch — войдите заново: «Доступ → Выйти → Войти через Twitch».
5. Проверка обновлений заработает после публикации этого релиза с тегом `v1.10.18`.

## Известные ограничения

- **TikTok** — неофициальный WebSocket и подпись Euler Stream; возможны лимиты и перебои. Отправка сообщений в TikTok не поддерживается.
- **YouTube** — нужен свой API-ключ и квота Data API v3.
- **Twitch** — для отправки нужен OAuth; для Confidential-приложения также Client Secret.
- Файлы не подписаны сертификатом — SmartScreen будет предупреждать.
- Для проверки обновлений через GitHub нужен опубликованный релиз; иначе будет «HTTP 404».
